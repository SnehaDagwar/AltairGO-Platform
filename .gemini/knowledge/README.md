# .gemini/knowledge/ — AltairGO-Platform Codebase Knowledge

This directory contains structured knowledge files for AI agents working on this codebase.

## Files

| File | Purpose |
|------|---------|
| `../GEMINI.md` | **Primary reference** — complete codebase knowledge base (architecture, API, design system, conventions) |
| `file-index.md` | Quick-lookup file index with sizes, line counts, and what each file does |
| `api-map.md` | Complete API function → endpoint mapping for fast lookup |

## Usage

When starting a new session, read `GEMINI.md` first. It contains everything needed to work on this project without re-reading source files.

For specific lookups:
- Need an API endpoint? → `api-map.md`
- Need to find a file? → `file-index.md`
